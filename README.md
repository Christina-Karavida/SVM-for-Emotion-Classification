# Emotion Classification using TF-IDF & SVM

NLP project exploring **emotion classification in conversational text**.

### Datasets

* **WASSA Tweets**
* **MELD (Multimodal EmotionLines Dataset)**
* **Eliza dataset**
* **GoEmotions** — Demszky et al. (2020)

### Approach

* **Bag-of-Words & TF-IDF** for text representation
* **SVM classifier** for emotion prediction
* **GoEmotions** for comparison
* Evaluation using accuracy, precision, recall, F1-score and confusion matrices

### Results

* SVM-based classifier: **56% accuracy**
* GoEmotions: **63.22% accuracy**
* Main challenges: **class imbalance and confusion between negative emotions**

### Technologies

`Python` · `NLP` · `Scikit-learn` · `TF-IDF` · `Bag-of-Words` · `SVM` · `GoEmotions`
